# Termoformado SATO

Aplicación Android para calcular la cantidad de piezas que entran en marcos de termoformado.

## Marcos
- 485 × 395 mm
- 485 × 495 mm
- 485 × 290 mm
- 485 × 340 mm

## Funciones
- Pieza circular o rectangular/cuadrada.
- Separación automática según altura y factor configurable.
- Prueba de orientación a 90° para piezas rectangulares.
- Comparación de los cuatro marcos.
- Selección automática de la mejor opción.
- Gráfico de distribución de piezas.
- Funciona sin conexión.

## APK
GitHub Actions compila automáticamente `Termoformado-SATO.apk` al subir cambios a `main` o al ejecutar manualmente el workflow **Compilar APK Android**.
